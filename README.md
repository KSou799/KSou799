# Sou Komiya

Mechanical engineering student at Metropolia University of Applied Sciences, Helsinki.
I design, build and test small engineering projects, from CAD and fabrication to simulation.

## Code on this profile
- [FlexiCity](https://github.com/KSou799/FlexiCity): load-shifting simulator built at Urban Circular Hack Helsinki 2025, team of 4. Cuts the modelled daily peak by 9.2% and flexible-load cost by 11.3%, benchmarked against an exact MILP solver. Python.
- [BMW i8 vehicle analysis](https://github.com/KSou799/BMWi8VehicleAnalysis): longitudinal dynamics model, checked against BMW's published 0 to 100 km/h time (model 4.6 s, BMW 4.4 s). MATLAB/Octave.

## Other projects
- PLC traffic light demonstrator: aluminium enclosure designed in SolidWorks, 16 3D-printed parts, Siemens LOGO! program
- Pedestrian bridge prototype, team of 5: carried 20 kg against a 6.3 kg requirement

**Tools:** SolidWorks, ISO 2768 drawings, LOGO! Soft Comfort, Python, MATLAB/Octave, 3D printing
